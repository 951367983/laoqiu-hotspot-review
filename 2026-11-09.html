今日周期定位（先说总判断）

主周期：市场把 11-05 的暴跌记成了"AI 监管"，但真正的重力是"美联储 12 月要加息"。

老仇讲过"AI 终究是个收益问题"。要给这句话补一个前提：在加息周期里，任何"未来收益"都要先被高贴现率砍一刀。 AI 不是不成立，是它的折现率变了。

事件一：A股 11-06 大跌，"独立性"测试没通过

一句话定性：换位置，不是塌方。钱没走，只是躲起来了。

① 识别标志性事件

指标 收盘 涨跌
沪指 3649.18 -1.10%
深成指 11175.78 -2.57%
创业板 2465.23 -3.96%
科创 50 1253.20 -2.6%
全市场成交 1.66 万亿 缩量 4635 亿
下跌家数 — 超 4700 只

杀的是算力硬件：东山精密、剑桥科技跌停，"易中天"三大光模块巨头早盘一度跌超 12%。 涨的是防御：新赛股份、万向德农涨停；沪农商行 +4%，建行、苏州银行 +2%；公路铁路、公用事业、电力飘红。 主力净流入前三：公用事业、银行、农林牧渔。

② 精确定性

换位置，不是塌方。三条证据：

  1. 缩量下跌不是恐慌。 恐慌会放量，人人夺门而出。缩量 4635 亿说明想卖的卖完了、想买的不敢进。
  2. 指数跌不等于全市场跌。 4700 只下跌的同时，银行、农业、公用事业在涨——结构在换，不是水位在降。
  3. 算力硬件跌、算力租赁涨，是最锋利的一刀。 润建股份连板、华胜天成触及涨停。市场不是不信 AI，是不信"买硬件能赚钱"，转去赌"租算力能赚钱"——同一产业，从资本开支逻辑切到现金流逻辑。

创业板 -3.96% 远惨于沪指 -1.10%。跌幅和科技含量成正比，和防御属性成反比。

③ 全局传导推演

先被定价的是"费城半导体 -12.25%"这个数字，不是"民主党监管"这个概念。 费半 11-05 单日跌 12.25%，创 2020 年以来最大单日跌幅，30 只成分股无一幸免。

  1. 费半暴跌 → A股算力硬件开盘杀跌（上午完成）
  2. 算力杀跌 → 创业板、科创 50 被拖（午后加速）
  3. 指数下跌 → 资金找避风港 → 银行、公用、农业（全天持续）
  4. 缩量 → 存量博弈 → 轮动加快、持续性变差

往后看：防御抱团推升红利资产估值；11-06 中概股反而普涨，说明跑的是内资的高位仓位，不是外资。

④ 资产影响（定量只对当下有效）

  • 算力硬件：短期仍有二次探底压力，反弹幅度会小于跌幅；
  • 红利/公用/银行：相对收益仍在，但估值已不便宜；
  • 创业板：结构上最脆弱，反弹需要"缩量止跌"确认。

⑤ 时间窗口

  • 小时级：11-09 开盘半小时定情绪（能否站回 3670）；
  • 交易日级：3 个交易日内若持续缩量阴跌，则换手失败；
  • 周级：一周内看防御板块能否连续强于科技，定"月度风格"真伪。

⑥ 操作含义（含误区自查 + 国家队视角）

该做：观望，等"缩量止跌 + 放量收红"再谈进攻；跟防御的相对收益，但别给它们成长估值。

不该做：把缩量下跌当"洗盘结束"——阴跌是越跌越没量；在银行、公用事业上"抄底"，它们是临时住处，不是进攻阵地。

误区自查：最容易犯的错是"用指数跌幅判断个股风险"。指数跌 1.1%，个股可以跌停，也可以涨停，指数从来不是个股的风险度量。

国家队视角：国常会是 11-06 晚上说的，当天指数跌了 1.1%。目标不是让指数涨，是不让指数崩。3649 可以接受；破 3600，政策才会真正下场。

⑦ 例外变量

  • 11-09 开盘半小时站回 3670 且放量 → 一次性换手，可恢复做多结构；
  • 连续三日缩量阴跌破 3600 → 政策底要二次确认。

事件二：国常会 11-06 再点名股市

一句话定性：政策底再确认，不是政策转向刺激。

① 识别标志性事件

11-06 国务院常务会议指出：完善资本市场稳市机制，增强股市内在稳定性，促进资本市场平稳健康发展。同一份文件还部署：加快重大项目和"六张网"建设、支持设备更新与无形资产投资、持续化解地方政府债务和中小金融机构风险。

时间点是关键：会议在指数跌 1.1% 的当天召开，当晚发稿。

② 精确定性

  1. "稳市机制"是制度语言，不是行情语言。 它说的是建立一套让市场不容易崩的机制（平准、回购、ETF 入市、长钱入市），不是"我要把指数拉到多少点"。
  2. "增强内在稳定性"最值钱。 内在稳定＝减少暴涨暴跌，意味着政策不喜欢暴涨，也不允许暴跌。对追涨的人是利空，对做波段的人是利好。
  3. 必须和"化债"绑在一起读。 同一段里既讲稳市、又讲化解地方债务和中小金融机构风险——股市和化债，在这份文件里是同一件事的两面。

③ 全局传导推演

最先被定价的是周一开盘的情绪，不是机制本身。 机制是慢变量，情绪是快变量。高开定的是"喊话"，低开定的是"上周五的惯性"。

  1. 国常会表态 → 11-09 开盘情绪 → 券商先动（政策情绪的温度计）
  2. "六张网" → 基建、电网、水利、交通（文件里唯一有实物量的部分）
  3. "设备更新、无形资产投资" → 机械、电力设备、软件
  4. "化解地方债务" → 城投、银行资产质量（最长、最慢、最重）

④ 资产影响（定量只对当下有效）

  • 券商：情绪弹性最大，但只反映"喊话"，不反映"落地"；
  • 基建/电网/水利：唯一有实物量的方向，可持续性最好；
  • 城投/银行：化债的直接对手盘，慢变量，不宜用短期波动判断。

⑤ 时间窗口

  • 小时级：11-09 开盘半小时；
  • 交易日级：3 个交易日内看有无实质配套（ETF 申购、回购、平准）；
  • 周级：一周内看"六张网"有无项目清单落地。

⑥ 操作含义（含误区自查 + 国家队视角）

该做：跟着"六张网"找实物量；盯配套动作是否落地。

不该做：把"稳市"当牛市发令枪；只盯股市，忽略"六张网"这个真正有增量的口袋。

误区自查：看到"稳市"就想"抄底"，是把"防崩"误读成"要涨"。防崩的目标是底部，不是顶部。

国家队视角：政策 11-04 在 3686 发力，11-06 指数 3649——已经跌破了自己的起跑线。从"稳市机制"的措辞看，政策倾向"让市场自己修复"，只在破位时出手。

⑦ 例外变量

  • 11-09 至 11-13 出现平准基金、大规模回购等实质配套 → 3649 是政策底二次确认；
  • 只有喊话没有动作且跌破 3600 → "政策底"要重估为"政策不愿兜底"。

事件三：非农 16.5 万、12 月加息概率 78%

一句话定性：降息叙事正式破产。这不是数据扰动，是周期重新确认。

① 识别标志性事件

数据 实际 预期 / 备注
10 月非农新增 16.5 万 预期 6.5 万
8–9 月修正 上修 8.4 万 —
失业率 4.1% —
平均时薪同比 +3.1% 超预期

市场定价：CME 显示 12 月加息 25bp 概率 78%，维持不变仅 22%；到明年 1 月累计加息 25bp 概率 67.1%。

连锁反应：美元指数 11-06 大幅上涨；COMEX 12 月金 4074.90（-0.94%）；伦敦金收 4069.99，失守 4100；高盛把 2026 年底目标从 4650 砍到 4150、2027 年底从 5400 砍到 4800，降幅均约 11%。

② 精确定性

  1. 一个月的非农可以是噪音，但"16.5 万 vs 预期 6.5 万 + 前两月上修 + 失业率 4.1% + 时薪 3.1%"是一组证据，不是单个数字。
  2. 78% 不是"可能"，是"几乎确定"。 市场不是在猜，是在等。
  3. 黄金失守 4100 不是技术回调，是实际利率重新上行。 加息预期 → 实际利率上行 → 不生息的黄金被压制，这条因果链是硬的。
  4. 高盛砍价是"跟随"不是"领先"。 它 11-05 就发了报告，当时金价 4147——卖方早就看到加息风险，只是没喊。

③ 全局传导推演

最先被定价的是美元指数，不是美股。 11-06 美元大涨是第一反应，然后才是黄金下跌、非美货币承压。股票最后反应，因为它还叠加了"AI 监管"这条噪音更大的线。

  1. 非农超预期 → 加息 78% → 美元走强（已发生）
  2. 美元走强 → 黄金失守 4100 → 白银跟跌（已发生，银 -0.83%）
  3. 实际利率上行 → 高估值成长承压（这条链被 AI 监管掩盖，但迟早要定价）
  4. 美元走强 → 新兴市场货币承压 → 外资流向（对 A股是慢变量，方向明确）
  5. 加息 → 美国财政付息成本上升 → 化债压力（最长的一条，也是"化债局"的全球版本）

④ 资产影响（定量只对当下有效）

  • 黄金：短期回调路径，4069 已破 4100 关，止损位在 4000；
  • 成长股：折现率上行，估值端有压制，业绩端暂未受损；
  • 美元计价资产：短期受益，但美国财政付息压力是反噬；
  • A股：通过汇率和外资两条慢链受影响，不是主因但不可忽视。

⑤ 时间窗口

  • 小时级：11-09 亚盘美元指数开盘方向；
  • 交易日级：本周内金价能否守住 4000；
  • 周级：至 12-09 议息，78% 的概率会被反复交易。

⑥ 操作含义（含误区自查 + 国家队视角）

该做：仓位放在现金流确定的资产（红利、公用、必需消费）；等 12 月议息落地再谈方向；把"加息 78%"当"还没跌完"，而不是"跌完了"。

不该做：只盯"AI 监管"这一个利空，忽略利率这个重力；在黄金上抄底，它的对手盘正在往上走；把预期当结果，78% 是预期，兑现前不会跌完。

误区自查：最容易犯的错是"把一次数据当一次性事件"。非农不是一天的新闻，是未来一年的利率起点。

国家队视角：美联储加息 → 中美利差走阔 → 人民币承压 → 中国央行 11-15 上调外汇存准率，就是这个压力下的应对。两条线是同一个故事的两端。

⑦ 例外变量

  • 12 月意外不加息（22% 概率）→ 美元回落、黄金反弹、成长股修复，是预期差大礼包；
  • 加息且暗示 2027 继续 → 全球风险资产估值底还要下移一档。

事件四：央行上调外汇存准率，连续 24 个月增持黄金

一句话定性：稳汇率 + 储备多元化的双轨操作，不是货币松紧信号。

① 识别标志性事件

项目 内容
外汇存款准备金率 4% → 6%，11-15 起生效
官方理由 加强金融机构外汇流动性管理
外汇储备（10 月末） 34052 亿美元，+49 亿（+0.14%）
黄金储备（10 月末） 7830 万盎司，+83 万，连续 24 个月增持

② 精确定性

  1. 外汇存准率不是降准/加息。 它管外汇资金流动性，不管人民币松紧。看到"上调"就喊收紧，是把两套工具混成一套。
  2. 上调 ≠ 贬值预期。 上调常见于抑制人民币过快升值，也用于管理顺周期波动。方向要看 11-15 前后的中间价和结售汇数据，现在只能定性为"防波动"，不能定性为"防贬值"。
  3. 连续 24 个月增持黄金是战略，不是交易。 不间断 24 个月，是储备结构再平衡，和外盘短期涨跌无关。央行买金不看 K 线，看的是美元体系的信用成本。

③ 全局传导推演

最先被定价的是离岸人民币汇率，不是 A股。 外汇存准率直接影响外汇市场流动性，股市要隔一层。

  1. 上调存准率 → 银行外汇资金成本上升 → 外汇波动收敛（11-15 生效）
  2. 汇率稳定 → 外资汇率风险溢价下降 → 北向更愿配置（慢变量）
  3. 外储 3.4 万亿、+49 亿 → 10 月没有大规模资本外流（这是"稳"的证据，不是"强"的证据）
  4. 连续增持黄金 → 全球央行购金需求的中国分量（世界黄金协会 Q3：央行净购金 321 吨、同比 +42%）

往后看两条对拉力：央行买金托长期底，实际利率上行压短期价。 这就是金价在 4069–4147 反复、而非单边的原因。汇率稳 + 加息周期，意味着 A股大概率是存量博弈 + 结构行情，不是全面牛市。

④ 资产影响（定量只对当下有效）

  • 人民币汇率：短期波动收敛，方向待 11-15 后确认；
  • A股外资：慢变量改善，不构成短期催化；
  • 黄金：长期底有央行托，短期价有实际利率压，两股力对冲；
  • 外汇相关金融股：成本上升，影响有限。

⑤ 时间窗口

  • 小时级：11-15 生效日前后，中间价与离岸价差；
  • 交易日级：生效后 3 个交易日看结售汇数据；
  • 周级：一周内看外汇市场波动率是否下降。

⑥ 操作含义（含误区自查 + 国家队视角）

该做：把汇率当背景音，稳住就安心做结构；汇率乱时先退到防守。

不该做：把外汇存准率当"放水/收水"信号；跟央行买金做短线——用战略的锤子敲投机的钉子。

误区自查：最容易犯的错是"把外汇工具当货币政策工具"。人民币的松紧看 LPR、存款准备金率；外汇的松紧看外汇存准率、逆周期因子。这是两套系统。

国家队视角：美联储加息、美元走强的同一周，中国在"稳汇率 + 加黄金"。这不是对抗，是给自己的货币加一道缓冲。老仇讲的化债局里，汇率稳定是前提——汇率一乱，化债成本就失控。央行这一手，本质是给化债争取时间。

⑦ 例外变量

  • 11-15 后人民币明显升值 → 这次是抑制升值、防热钱涌入；
  • 仍承压、结售汇逆差扩大 → 稳汇率压力更大，后续可能有逆周期因子、离岸央票。

③ 全局传导推演

最先被定价的是超跌的算力硬件，不是整体风险偏好。 跌得最狠的弹得最高，这是空头回补，不是多头进场。

  1. 超跌反弹 → 空头回补 → 指数修复（已完成）
  2. 非农超预期 → 加息 78% → 反弹天花板被压低（定价未完成）

  4. 全球利率共振 → 所有"靠低利率活着"的资产承压

反弹后再跌，第二次往往更痛：第一次是杠杆爆仓，第二次是基本面下修。

⑥ 操作含义（含误区自查 + 国家队视角）

该做：把反抽当减仓机会；等 12 月议息落地再谈方向。

不该做：把反抽当反转——反弹幅度小于跌幅就是下跌中继；用"监管缓和"解释反弹，直接原因是超跌 + 空头回补。

误区自查：最容易犯的错是"看单日涨跌定趋势"。趋势看周线，情绪看日线，结构看月线。用日线判断趋势，是本轮最大的错误来源。

国家队视角：美股反抽不代表美国政策转向。加息 78% 的预期还在，趋势的天花板没被拆掉。

⑦ 例外变量

  • 反弹在 24800 受阻回落 → 斜向下成立。

综合判断

  1. 市场把暴跌记成了"AI 监管"，但重力是"加息"。 非农 16.5 万、加息 78%、美元大涨、黄金失守 4100——这四件事是一件事。盯头条做投资永远慢一步，盯利率才知道重力在哪。
  2. A股"独立性"没通过，但也没崩。 4700 只下跌、缩量 4635 亿、银行农业公用逆势涨。换位置，不是塌方。
  3. 政策底和市场底差 50 点。 政策 11-04 在 3686 发力，11-06 收 3649。政策能接受 3649，不能接受 3600 以下。这就是"稳市机制"最实在的含义。
  4. 我第一次方向判错，错在用设问留退路。 心里倾向"能收红"，嘴上写"考试"。这个错比"时点保守"更值得记——因为它不是能力问题，是诚实问题。
  5. 最有价值的收获是把判断写成条件。 黄金那条自动触发，不需要解释也无法辩护。以后能写成条件的，一律写成条件。
  6. 央行这一手是给化债加缓冲。 汇率稳，化债成本才可控；汇率乱，一切失控。化债局的地基是汇率。
  7. 操作总纲：今日看 3640 能否站住；不追家电反抽、不抄黄金的底、不把防御当成长；仓位放在现金流确定的地方。存活优先——反抽是减仓机会，不是加仓理由。
